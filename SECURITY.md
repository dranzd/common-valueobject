# Security Policy

## Supported versions

Security fixes are released for the latest `1.x` minor version.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub's
[private vulnerability reporting](https://github.com/dranzd/common-valueobject/security/advisories/new).
Include the affected version, a minimal reproduction, and the impact you expect.

You can expect an acknowledgement within a week. Once a fix is released, the
advisory is published and the reporter is credited unless they prefer otherwise.
